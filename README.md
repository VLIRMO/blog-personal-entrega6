# Portafolio de Desarrollo Web

Proyecto final del curso de Desarrollo Web. Sitio web responsivo desarrollado con HTML5, SCSS/CSS y control de versiones con Git.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**: Estructura semántica de las páginas.
- **Sass (SCSS)**: Modularización de estilos mediante partials (`@use`), variables, mixins y media queries.
- **CSS3**: Estilos compilados y diseño responsivo.
- **Git & GitHub**: Control de versiones.
